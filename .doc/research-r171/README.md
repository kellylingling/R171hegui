# 来源索引与本地采集

[sources-manifest.json](sources-manifest.json) 记录方案引用的来源、核查日期、原始链接及本地采集文件 SHA-256。

索引中的文件名指本次核查时工作区的本地采集件。它们包含网页界面等内容，不能把采集件摘要理解为法规 PDF 的官方校验值。远端内容变化后重新下载，摘要可能不同。

版本库保留来源索引和原创分析，不分发第三方新闻网页全文、搜索结果及浏览器临时文件。原文可通过索引链接访问。本地采集件仍保留在原工作区，未被删除。

法规生效结论通过 01 系列公布文本、补充条款、WP.29 通过记录与 RDW 日期表交叉核对。标题含 Proposal 的联合国文本须结合通过记录和生效信息判断，不能仅凭标题认定已生效。

渲染脚本：从仓库根目录运行 `python .doc/research-r171/render_architecture.py`；依赖 Python 与现有 Edge，不需要第三方 Python 包。
